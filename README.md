# CrossFly project website

Static research project page for **Benchmarking Interaction-Oriented Aerial Mobility Across Heterogeneous Environments**.

## Structure
- `index.html`: page content, research figures, and media placeholders
- `style.css`: responsive academic layout
- `script.js`: results tabs and expandable figures
- `assets/`: extracted paper figures; no manuscript PDF
- `.nojekyll`: serve the static files without Jekyll processing

## Media
The teaser, four task demonstrations, and two interaction-readiness comparisons intentionally remain empty until final media is supplied. The manuscript remains anonymous. Its PDF is deliberately excluded, and Paper controls are placeholders. Do not commit a PDF without renewed permission.

## GitHub Pages
The site uses relative asset paths, so it works beneath a repository project path. No build step is needed. When publication is approved, configure Pages to deploy from the root of the main branch.

The owner permits public website/source/figure publication; the PDF is excluded. Prefer a private repository when the account supports private-repository Pages; a public repository is approved if needed. Private-repository Pages requires an eligible GitHub plan.
